## 📂 Estructura del Repositorio

El repositorio está organizado en carpetas independientes para cada una de las prácticas exigidas, conteniendo cada una su propio proyecto completo de Android Studio:

| N.º | Carpeta del Proyecto | Contenido / Práctica Principal |
| :--- | :--- | :--- |
| **1** | `1_EnrutamientoAvanzado/` | **Enrutamiento Avanzado:** Fragmentos, Navigation, SafeArgs y deep links. |
| **2** | `2_MisTareas/` | **Mis Tareas 1:** RecyclerView, Adapter, ViewHolder y menús (popup, contextual y opciones). |
| **3** | `3_MisTareas2/` | **Mis Tareas 2:** SharedPreferences, AlertDialog, DatePicker, Toast y Snackbar. |
| **4** | `4_MiBiblioteca/` | **Mi Biblioteca:** Entidades Room, DAOs, base de datos local y gestión de hilos. |
| **5** | `5_NoticiasFP/` | **Noticias FP:** Material Design, Tema, Toolbar, Drawer, CardView, Chip y FAB. |
| **-** | `evidencias/` | **PDF de Evidencias:** `Hito2_Evidencias_Lopez_Garcia.pdf` con las capturas funcionales de todas las apps. |
